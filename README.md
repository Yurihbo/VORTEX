# VORTEX — Biblioteca Virtual

VORTEX é uma biblioteca pessoal digital com estética de fantasia medieval e biblioteca arcana, desenvolvida por Yurihbo. O projeto foi estruturado com tecnologias modernas para organizar e acompanhar suas leituras e jornadas literárias.

## Recursos

- **Dashboard:** Panorama completo da coleção, estatísticas e sugestões de leitura diária.
- **Biblioteca:** Gerenciamento de tomos com busca, filtros de status, ordenação e opções de visualização.
- **Grimório Detalhado:** Acompanhamento de páginas, status de leitura, favoritos, notas pessoais e fragmentos marcantes.
- **Metas e Desafios:** Desafio anual de leitura e contador da chama diária de constância.
- **Conquistas:** Marcos desbloqueados conforme sua evolução na estante.
- **Estatísticas:** Análise de leituras por mês e reinos do conhecimento.
- **Perfil e Dados:** Exportação e importação de backup em formato JSON.
- **PWA Instalável:** Funciona offline com service worker, cache de navegação e atalho de instalação.

## Executar localmente

Certifique-se de possuir o Node.js 20+ e o gerenciador de pacotes pnpm instalados em seu ambiente.

```bash
pnpm install
pnpm dev
```

O servidor de desenvolvimento estará acessível em `http://localhost:3000`.
